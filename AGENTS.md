# AGENTS.md

Instrucciones para cualquier agente de IA que trabaje en este repositorio.

## Antes de empezar

1. Lee `SOUL.md` para entender el tono y los valores.
2. Lee `DESIGN.md` antes de producir cualquier pieza visual.

## Dónde guardar cada cosa

- Investigación y fuentes → `investigacion/`
- Piezas visuales → `diseno/`, `imagenes/`, `web/`, `presentaciones/`, `videos/`
- Análisis y resultados → `reportes/`

## Reglas

- Escribe en español.
- Cita las fuentes de cualquier dato.
- Usa las plantillas de `plantillas/` cuando existan.
- Si una tarea se repite, conviértela en una skill dentro de `skills/`.
