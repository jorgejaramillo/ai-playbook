# IA Ejecutiva

Ejemplo para clase de IA corporativa: un repositorio organizado para trabajar con agentes de IA en proyectos de negocio.

## Archivos base

| Archivo | Para qué sirve |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Instrucciones de trabajo para los agentes de IA (cómo operar en este repo). |
| [`SOUL.md`](SOUL.md) | Identidad, tono y valores: la "personalidad" del proyecto. |
| [`DESIGN.md`](DESIGN.md) | Sistema visual: colores, tipografía y lineamientos de diseño. |

## Estructura

```
├── skills/          Habilidades reutilizables para los agentes
├── investigacion/   Hallazgos, fuentes y datos
├── referentes/      Benchmarks y casos de inspiración
├── imagenes/        Imágenes generadas o recopiladas
├── diseno/          Piezas y recursos de diseño
├── web/             Páginas, prototipos y código web
├── presentaciones/  Decks y presentaciones
├── videos/          Guiones, storyboards y videos
├── reportes/        Reportes de análisis y resultados
└── plantillas/      Plantillas reutilizables
```
